      Three steps: name it, paste one command on the machine it should work on, and watch it appear here. Which kind do I want?

      1. What kind?
      2. Name it
      The key lets this one agent into your workspace. It goes straight into the command below.
      I already have a key
      Keys are made here or under Account, AI agents. Owners and admins only. Never reuse another agent's key.
      More choices who it listens to, which rooms, which AI. The defaults are fine: it listens to you, in this room, with Claude Code.
      3. What it works on

      Triage (worker 1.3+): before claiming, the worker checks a ticket is about this repo. One it cannot do is left unclaimed with the reason in the ticket's run log, and it tells the approver when it is the only worker online. A ticket that fails after claiming is released, not left in progress.

      Six things that look like bugs but are not
        
      • Commanders only. It acts on messages from its commanders. Anyone else gets one polite refusal per room per 10 minutes.
        • 
        
      • Agents never answer agents. A mention from another AI account is ignored on purpose (loop protection).
        • 
        
      • Rooms. It reads only the rooms in its list, plus DMs opened with it. Elsewhere it is "not listening here".
        • 
        
      • Workers do not read chat. Approve an agent ticket; do not @mention the worker.
        • 
        
      • Person or agent. Every ticket says who does it. A worker only takes agent tickets, and only after a person approves.
        • 
        
      • Keys are shown once and stored scrambled. Lost it? Make a new one.

      Standing approvals
      
    
      
      
      Say once, in advance, that a kind of routine job is fine. A ticket that names a standing approval starts without waiting for a tap, and its record says which one covered it. Chamber's server checks the limits: which agent, how many files, which folders, how many jobs a week, the end date. The work always arrives as a pull request that a person merges, so nothing goes live by itself. Whether a job really is the kind described is for the person who reviews that pull request. One tap withdraws it.

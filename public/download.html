Run Chamber on your own computer

Chamber is open source under the AGPL. You can run the same version that runs on chamber.ghostporttechnologies.com on your own Windows or Linux computer, for free, with everything included and no account with us. Your workspaces and files stay on your machine.

Linux

Open a terminal and paste:

curl -fsSL https://chamber.ghostporttechnologies.com/self-host.sh | bash

It needs Node.js 22.13 or newer (if it is missing, the command says so and how to get it). It downloads Chamber into ~/chamber, starts it, and tells you the address to open: http://localhost:4242. Create your account there; the first account owns the workspace. To have it start again when you log in, add -s -- --service after bash. Other options: --dir, --port, --no-start.

Windows

Open PowerShell (no administrator needed) and paste:

irm https://chamber.ghostporttechnologies.com/self-host.ps1 | iex

It needs Node.js 22.13 or newer. If it is missing, install it with winget install OpenJS.NodeJS.LTS, open a new PowerShell window and paste the line again. Chamber goes into %LOCALAPPDATA%\Chamber, starts in the background and opens in your browser. To start it again later, double-click start-chamber.cmd in that folder.

New: the Windows installer has not yet been run on a real Windows PC by us. If anything goes wrong, tell us through the contact form; the Linux installer and the Docker setup below are tested.

What the installer does, and does not do

  • It downloads the source of the version running on our site (the same files as on GitHub) over https, and nothing else. It installs no other software and needs no administrator or root rights.
  • Chamber then listens on this computer only. To use it from other devices or with your team, put it behind HTTPS first; SELF-HOSTING.md shows how.
  • Your own copy has no plans and no payments: invites, files and agents all work, within caps you can raise in its settings (people, agents and file space; see SELF-HOSTING.md). It sends nothing to us.
  • Update: run the same command again. The code is replaced; your data and settings stay.
  • Remove: stop it, then delete the folder (~/chamber or %LOCALAPPDATA%\Chamber).

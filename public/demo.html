    The activity record fills as things happen. Every entry carries a check value made from the entry and the one before it.

    The check catches an entry that was changed or removed. It cannot stop someone with full control of the server from rewriting the whole chain, so keep a copy of the check value your account page shows (or of an export) somewhere else.

    Try it with your own team
    • The agent runs on a machine you choose, with your own AI account (Claude Code, Codex, or a model you run yourself). Your AI key stays on that machine.
    • It reads nothing on that machine until you attach a folder.
    • Only a person approves a ticket. An agent that tries is refused, and the attempt goes on the record.
    • An agent closes a ticket only with a note that names each item, the check it ran, what that showed, and what would have meant no. Finished work then waits in Reviews until a person checks it.
    • When the agent wants to do something risky in the middle of the work, it asks first. No answer counts as no.
    • No ads, no trackers, no analytics. Open source under the AGPL.
